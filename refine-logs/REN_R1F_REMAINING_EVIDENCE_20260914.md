# Ren R1F 剩余证据与最短推进路径

2026-09-14。承接已完成的全量记录时序审计；本文件不是放行，也不更改原 P1-R1 或新 P2 人工批准要求。

## 已解决的具体问题

233 文件按来源规则形成 113 个命名候选组。全量 104,190,778 条记录及 1,520 个表/分片边界的编号连续性无缺口、重复或回退；无无效 key、cycle 回退或同工步时间下降。这排除了当前顺序下的这些具体拼接异常，不证明不同组没有部分相同测量。

固定作者 README 明确声称四批共 113 个超级电容，每个电容一个 Excel 记录。来源声明与主文件/续片规则和实际连续性一致，是身份映射的正面证据，不能忽略；但记录编号/文件名本身仍不是跨组独立性证明。不要凭空增加必须有制造商序列号等原协议未要求的门槛。

## 剩余工作

| Gate | 现有证据 | 下一项实际验证 | 不能替代它的证据 |
|---|---|---|---|
| identity | 作者 113 设备声明；113 主文件；组内分片连续 | 对照数据说明中的批次/设备映射与行级组特征，并结合跨组重叠检查；区分来源声明、行证据和推断 | 仅文件名或总文件数 |
| duplicate/overlap | 完整容器和 Workbook 完全相同组为 0；相邻 key 重复为 0 | 新只读候选检查跨组完整测量片段重叠；不把常见零电流/恒压点或共享编号当重复设备 | 不同文件哈希、五字段 metadata key |
| target/unit | record 表明示 V、mA、mAh；作者固定 20 mA 推导路径已静态审查 | 对照 step/cycle 汇总与记录的状态、实际电流、时间端点、电压差；审计单位和可推导性，不输出数值目标 | mAh 直接当 F；执行作者预处理输出当真值 |
| event/censor | 当前时序只证明记录顺序 | 来源支持的阈值、观测终止原因和阈值可观测性分别登记；无法证实则 RUL 不合格 | 序列最后一点就是失效 |
| split | 113 个命名组，四批分布 28/25/30/30 | 身份及重复组确定后，冻结 whole-unit 与跨工况候选划分；全部预处理按训练侧拟合 | 随机分窗口、同组续片落入不同折 |

## 下一实现的边界

不重跑已完成的 archive、解压或 schema。新增只读审计模块应复用冻结 Workbook-only 边界，以新版本、合成对抗测试和独立 pre-run review 放行后，合并采集后续必要证据，避免为每个字段反复扫描全量 XLS。

跨组局部重叠应比较连续的完整测量记录或等价可复核表示，并记录匹配长度、所属候选组与原始位置；重复前缀/静置片段不得直接推断同一设备。具体表示、最短匹配长度及裁决规则必须在新运行前固定，不能查看匹配后调规则制造通过。

目标审计只给 eligibility 和理由；ESR 不得因存在电流、电压列就自动判定可得。容量预测与 RUL 资格分别裁决；新 P2 必须明确可用目标，不以目标缺失补造全套输出。

本文件没有授权模型、API、GPU、RUL、外部消息或新的数据集替换。遇到无法解决的身份/目标证据缺口，按原计划记录限制或提出替代数据路线，不降低 Gate。
