# Experiment Plan: AUDIT-Cap v0.2

**Problem**：公开电容退化数据在器件身份、测量可用时刻、EOL/删失和工况语义未经审计时，模型排行榜容易测量标签倒计时或时间泄漏，而非在线 RUL 能力。  
**Method Thesis**：先用可机器重建的数据/标签审计和设计仿真冻结可识别 estimand，再在同一 append-only rolling ledger 上建立简约 CPU 基线。  
**Date**：2026-08-13  
**Status**：H0 approved；`AUTO_PROCEED=false` 仍适用于 Data/Design/Freeze B 门后的扩展。

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |
|-------|----------------|-----------------------------|---------------|
| C1 可审计 benchmark | 没有身份、时间和结局语义就不存在可信 RUL Eval | raw hash→HDF5 tree→unit/event/label ledger 可由独立脚本重建；未知字段显式 quarantine | B0, B1 |
| C2 条件简约基准 | 真实精度必须先超过强简单模型 | 严格 LOCO rolling、逐器件宏平均、合法内层选择、完整预测账本 | B2, B3 |
| Anti-claim | 防止窗口伪样本量和末尾伪 EOL | 植入泄漏测试必须失败；设计仿真揭示选择错误率/CI 宽度 | B1, B2 |

## Paper Storyline

- **Main paper must prove**：数据/标签可复建；端点是否可识别；简单模型在真实未见电容上的单位级表现。
- **Appendix can support**：ESR 阈值敏感性、连续越界 q、设计仿真全网格、parser 对象树。
- **Intentionally cut**：TRACE-Cap 全栈、动态路由、TSFM 微调、Physics-CDE、五种 Agent 拓扑和未经新数据的部署主张。

## Experiment Blocks

### B0：源字节与 schema 审计

- **Claim tested**：C1。
- **Why**：决定 Benchmark L 是否存在、哪些模态/器件/结局可用。
- **Dataset**：官方 Stress-2 ZIP；PHM Society 的 5,038,942,729 B Electrical Stress ZIP（ES10/12/14 MATLAB 7.3）。
- **Procedure**：记录 URL/HEAD/时间/bytes/SHA-256；ZIP CRC；逐 MAT SHA-256；HDF5 tree、MATLAB class、shape、dtype、references、时间范围、NaN/Inf；推断与证据分列；unit/modality/event/termination/duplicate ledger。
- **Outputs**：`DATA_MANIFEST.json`、`HDF5_OBJECTS.csv`、`AUDIT_SUMMARY.json`、`AUDIT_REPORT.md`、quarantine 清单。
- **Success criterion**：三个 MAT 均通过 CRC/HDF5 读取；每个用于评测的记录能追溯到源对象与物理器件；未知终止不被重标。
- **Failure interpretation**：不能映射器件/时间/配对就禁用 C3；不能判定结局就禁用 RUL，只保留 C/ESR。
- **Priority**：MUST-RUN。

### B1：标签、回放与 Design Gate

- **Claim tested**：C1 与 Anti-claim。
- **Why**：验证数据量是否支持比较，而不是把窗口当独立样本。
- **Dataset/split**：先在 Benchmark S 验证；再用 B0 实际结构参数化 Benchmark L 仿真。仿真单位始终是物理电容。
- **Compared analysis**：无效的按窗口 IID/随机切分仅作为 leakage sentinel；有效方案为 unit-cluster LOCO 和 cluster-level inference。
- **Simulation**：零效应与相对最强基线的最小有意义效应（MAE 改善 0/5/10/15%）；网格覆盖 n_units、每单位长度、事件率、右/区间删失、单位随机效应、AR(1) 残差和不等区间宽度；至少 2,000 Monte Carlo repeats/格（快速 sanity 为 200）。
- **Metrics**：选择错误率、coverage、CI 宽度、模型胜出概率、无冠军率、单位级效应偏差；禁止以窗口数作为 n。
- **Success criterion**：零效应错误晋级≤5%；目标最小效应下 coverage 90–95% 且检出率≥80%，或明确报告该结构无法支持比较。
- **Failure interpretation**：Freeze B 不允许优越性裁决；只报告描述性单位结果/负结论。
- **Priority**：MUST-RUN。

### B2：Benchmark S 回放器与最小基线 sanity

- **Claim tested**：C2 与 Anti-claim。
- **Dataset/split/task**：6 只×11 时点 Stress-2；6-fold LOCO；初始上下文 4，h={1,2,3}，同时报告 context 3/5 敏感性；C-loss 和 ESR-increase 多步预测。
- **Systems**：last-value、global drift、local-linear(k∈{2,3,4})、指数趋势、local-level/local-trend Kalman、ridge causal window。
- **Metrics**：按 unit×target×horizon 的 MAE/RMSE/MASE；逐只预测 CSV；C-EOL 只做区间/右删失标签实现验证，ESR-RUL=`NA`。
- **Setup**：无 GPU；无随机行切分；所有 scaler/参数/窗口选择只用内层训练器件；确定性模型 seed=20260813。
- **Success criterion**：所有预测哈希通过未来标签置换不变量；last-value 可手算复核；输出行数与合法原点一致；复杂基线若不优于 last-value 也如实保留。
- **Failure interpretation**：回放/指标有错则禁止进入 Benchmark L；模型负结果不算 pipeline 失败。
- **Priority**：MUST-RUN。

### B3：Benchmark L 最小 C/ESR 基线

- **Claim tested**：C2。
- **Eligibility**：只有 B0 Data Gate 与 B1 Design Gate 相应端点通过后启动。
- **Dataset/split**：每应力电压内 LOCO；LOVO 只称 leave-one accelerated-stress voltage transfer。身份/板卡重复先合并或隔离。
- **Systems**：B2 中通过 sanity 的 last-value、最强 drift/local-linear、一个 state-space、一个 ridge。每次只增加一个自由度。
- **Primary endpoint**：在看到任何候选外层结果前，依据 B0/B1 填入 Freeze B；默认候选是宏平均 one-step C 相对变化 MAE，但不是在审计前强行冻结。
- **Secondary**：ESR 与 h=2/3；RUL 只有 termination/event gate 通过才加入，且不能把区间端点当真值。
- **Success criterion**：一次封存评测产生完整逐器件 ledger；程序自动输出 champion/no-champion；不做结果解封后调参。
- **Failure interpretation**：若最强简单模型不稳定，复杂模型全部后置；若数据不足，发布 benchmark/限制报告。
- **Priority**：MUST-RUN conditional。

### B4：条件测量桥（本轮不自动执行）

- **Claim tested**：EIS—瞬态概率观测映射是否有单位级增量。
- **Eligibility**：充分近同步配对、器件/板卡/仪器/温度元数据和 Design Gate 全部通过；需新的人工检查点。
- **Compared systems**：direct transient、time-trend negative control、simple errors-in-variables、一个固定 C3 挑战者。
- **Priority**：NICE-TO-HAVE / HUMAN GATE。

## Run Order and Milestones

| Milestone | Goal | Runs | Decision Gate | Cost | Risk |
|-----------|------|------|---------------|------|------|
| M0 | 完整下载、CRC/hash、schema | R000–R004 | Data Gate | 0.5–4 CPU h；约 11 GB raw | HDF5 引用复杂、无 README |
| M1 | 回放器与标签 sanity | R010–R012 | 所有不变量/手算测试通过 | <1 CPU h | 时间轴/单位误读 |
| M2 | 设计仿真 | R020 quick，R021 full | Design Gate | 1–8 CPU h | 仿真假设过窄 |
| M3 | Benchmark S 基线 | R030–R035 | harness gate | <1 CPU h | n=6，只能描述 |
| M4 | Benchmark L 最小基线 | R040–R043 | Freeze B | 2–12 CPU h | 事件/身份不足 |
| M5 | 条件扩展 | R050+ | 新人类检查点 | 未估 | 不在本轮自动范围 |

## Compute and Data Budget

- **Total estimated GPU-hours**：0。
- **CPU**：4–20 小时，设计仿真可多核但固定线程数。
- **Data**：5.04 GB ZIP + 5.17 GB MAT；派生审计预计 <2 GB，特征不预生成全量窗口。
- **Human evaluation**：Data Gate 后抽样核对字段语义与 Freeze B；B4 前新检查点。
- **Biggest bottleneck**：原始 HDF5 中器件、模态、时间和终止原因是否可唯一映射。

## Risks and Mitigations

- **未知终止/信息性删失**：RUL=`NA`，先做 C/ESR。
- **重复器件/板卡混杂**：生成 duplicate candidates；未消歧前同组隔离。
- **窗口伪样本量**：所有推断按物理器件 cluster。
- **外层适应**：容器/配置/hidden split 在解封前哈希；解封后修改只算探索性。
- **第三方代码许可**：不复制无 LICENSE 仓库代码，全部 clean-room。
- **凭据泄漏**：本轮不用远程 LLM API；任何后续 AgentPlan 凭据只来自未跟踪环境变量。
