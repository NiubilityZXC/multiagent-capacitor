# 电容在线预测冻结评测协议 v0.2

**状态**：审计前协议冻结；等待人类检查点批准后方可下载大包或运行正式数值实验。  
**冻结日期**：2026-07-29。  
**首要目标**：真实未见电容，以及同一加速实验内留一应力电压的数值预测精度；Agent 叙述、投票或主观评分不得替代任何指标。

## 0. 两阶段冻结与识别门

当前尚不知道 ES10/ES12/ES14 的独立器件数、EIS—瞬态配对数、终止原因和阈值事件数，因此不能诚实地预先声称 Benchmark L 已经可做 RUL、生存、共形或复杂模型比较。本协议冻结的是**审计过程和分支规则**：

1. **Freeze A（本文件）**：冻结下载来源、哈希要求、字段审计、标签语义、时间回放、泄漏规则和不允许执行的分析。
2. **Data Gate**：从原始 MAT 机器重建逐器件清单；必须包含器件/板卡/批次、电压、时间、模态、配对、缺失、阈值区间、终止原因和跨资源重复关系。
3. **Design Gate**：按真实器件数、事件率、删失率、配对结构和时间相关性做设计仿真，报告零效应选择错误率、最小有意义效应的检出能力和区间宽度。
4. **Freeze B**：在不查看任何候选模型外层结果的条件下，由人类批准唯一主要 endpoint、唯一主要模型对比、非劣界、缺失/无事件规则和平局规则；随后封存容器和分析脚本，由隔离执行者一次性解封。
5. 若 Data Gate 或 Design Gate 失败，自动降级为 C/ESR 轨迹的描述性/预测基准；RUL、生存、测量桥或复杂模型中相应不可识别的部分标为 `NA`，不得以其他指标顶替。

因此，v0.2 是可执行的审计前冻结协议，不冒充尚不可能完成的结果前主分析注册。

## 1. 不可变评测对象

### 1.1 独立样本单位

- 最小独立统计单位是**整只物理电容**，不是窗口、波形采样点或 EIS 频点。
- 同一只电容生成的所有窗口必须属于同一个外层折。
- 身份不明或可能重复的 Stress-2 与 ES10 轨迹，在证明不同源之前不能分别落入训练和 Eval。

### 1.2 两级基准

**Benchmark S（稀疏、完全核验）**

- 数据：Stress-2，10 V，6 只电容，每只 11 个 aging-time 点。
- 外层：6 折 leave-one-capacitor-out（LOCO）。
- 事件：20% C-loss 下 5 个区间删失事件、1 个右删失；4 个事件只在最终 194 h 点首次观测到。ESR 相对增幅最大 53.54%，无 \(R/R_0\ge2\) 事件。
- 用途：统计/滤波模型、小样本极限、泄漏测试、回放器正确性和删失实现验证。
- 禁止：以 66 个点为样本做随机交叉验证；在此数据上微调大模型并宣称泛化。
- 禁止：仅凭该小表比较 ESR-EOL RUL；该端点无事件，只能评价 ESR 轨迹预测。

**Benchmark L（多模态、多应力电压，待全量审计后冻结）**

- 数据：ES10/ES12/ES14 原始 EIS 与瞬态。
- 外层 A：每个电压内 LOCO。
- 外层 B：leave-one-voltage-out（LOVO），依次完整留出 10/12/14 V；只解释为同一加速过压实验内的“留一应力电压迁移”，不解释为跨真实工况。
- 外层 C：若器件类型/批次元数据允许，再做 leave-one-batch/type-out；否则标记不可执行。
- 最终样本数和可用事件必须由 HDF5 审计清单生成，不能引用第三方 README 代替。

## 2. 标签与目标

### 2.1 主任务定义

- 主 EOL：电容量首次被观测为 \(C/C_0\le0.8\)。
- 敏感性 EOL-1：ESR 首次被观测为 \(R/R_0\ge2.0\)。
- 敏感性 EOL-2：上述任一事件先发生。
- 敏感性 EOL-3：连续 \(q\) 个点越界；\(q\) 只能由训练/验证折确定并在 Eval 前冻结。
- 第一次离散越界形成区间删失 EOL；实验结束未越界形成右删失。

### 2.2 每个预测原点的输出

每获得一个新测量事件 \(t\)，系统只读取 \(\mathcal H_t\)：

1. 未来 \(h\in\{1,2,3\}\) 个测量事件的 C、ESR、\(SOH_C\)、\(SOH_R\) 和复合阈值余量。
2. 若物理时间轴可用，补充预冻结的小时尺度 horizons；不以插值制造新标签。
3. 条件 RUL 分布或生存曲线；只有结局与删失机制通过识别门后才计分，对右删失样本不计算伪造的点 RUL。
4. 50%、80%、90% 预测区间/分位数。
5. 未来 \(H\) 内阈值穿越风险、创新异常风险和跨模态不一致风险。
6. 推理延迟、模型版本、代码提交、输入快照哈希和路由理由。

## 3. 严格时间回放

1. 每只测试电容按原始时间顺序回放。
2. 初始上下文：
   - Benchmark S：至少 4 个已观测点；同时报告从第 3/5 点起的敏感性。
   - Benchmark L：按 EIS/瞬态事件的真实可用性冻结；不得为满足模型上下文而看未来。
3. **长期通道**读取从首个点到 \(t\) 的全部历史；**近期通道**只读取长度 \(k\) 的后缀。\(k\) 在内层训练/验证中选择。
4. 预测必须在未来标签到达前写入 append-only 账本。
5. 一个 \(h\)-步 C/ESR/SOH 预测只有在第 \(t+h\) 个真实事件到达后才能计分或进入相应短期校准器。阈值风险在风险窗口结束或事件发生后成熟。
6. 某预测原点的真实 RUL 通常直到该器件 EOL 或删失时才揭示；它**不得**在 \(t+h\) 时假定成熟。LOCO 测试期的 RUL/生存校准器固定为内层训练器件拟合的版本，不用该测试器件终末结局回填早期预测，也不使用同折其他 Eval 器件更新。
7. 若另行研究“器件依次服役后的跨器件在线校准”，必须预先冻结器件部署顺序，并作为与 LOCO 不同的 estimand 独立报告。
8. 测试电容的过去已揭示 C/ESR 可按预注册规则更新个体状态；其未来、终末结局、同折其他 Eval 电容和最终汇总结果始终不可见。
9. 在线更新、周期重训和不重训三种策略必须分开报告。

## 4. 嵌套切分与模型选择

对每个外层 LOCO/LOVO 折：

1. 外层 Eval 单元完全隔离。
2. 其余电容再做内层 group-wise LOCO/LOVO，用于：
   - 特征选择；
   - 归一化、填补和平滑器拟合；
   - 窗口长度、阈值和超参数；
   - 路由器、融合器和共形校准器；
   - 早停与模型族选择。
3. 任何新 Skill、Agent prompt、代码补丁、特征或模型一旦看到外层结果，即产生新版本；旧外层结果不能再用于无偏模型选择。
4. 正式论文只允许一个预注册主分析；探索性追加必须清楚标为 post-hoc，并使用新的影子/外部数据验证。

## 5. 基线阶梯

所有候选共享相同预测原点、输入可用性和 Eval 账本。

1. **朴素**：last value、drift、局部线性、季节性不存在时不使用季节模型。
2. **统计退化**：指数、Verhulst+指数、样条/混合效应、Wiener、Gamma、inverse-Gaussian、两阶段模型、联合退化—生存。
3. **状态空间**：KF、EKF/UKF、PF、switching/hidden semi-Markov；相同状态方程下比较滤波器。
4. **传统 ML**：ridge/elastic net、SVR、random forest、XGBoost/LightGBM、GPR；全部使用因果窗口特征。
5. **专用 RUL/生存**：AFT/Cox、离散时间 survival、RVM/GPR RUL、TCN/CNN-LSTM；删失处理必须一致。
6. **现代时序**：N-HiTS、PatchTST、TFT/TCN、Neural CDE；规模受小样本约束。
7. **基础模型**：Chronos、TimesFM、Moirai、Lag-Llama 的冻结零样本、轻量适配和可拒绝版本。
8. **融合**：静态平均、stacking、Bayesian model average、基于过去 prequential loss 的 Hedge、变化点感知软路由。

若一个实现失败或资源超限，报告 FAIL/NA；不能静默用别的模型替换。

## 6. 数值指标与唯一裁决

### 6.0 Freeze B 必填字段

正式结果解封前，注册表必须只有一行主分析，至少冻结：

```text
primary_endpoint
primary_horizon
primary_estimand
primary_comparison
eligibility_gate
noninferiority_bounds
missing_and_no_event_rule
tie_rule
sealed_container_hash
hidden_split_manifest_hash
```

Benchmark S 默认只验证回放器和小样本行为：主描述量为按电容宏平均的一步 C-loss MAE，并逐只公开；它不承担复杂系统优越性裁决。Benchmark L 的主字段只能在 Data/Design Gate 后、任何候选外层结果解封前填写。锁定分析程序必须在模拟的全部边界情形上无人工判断地产生“候选 A”“候选 B”或“无冠军”。

### 6.1 主要排名：Pareto + 预冻结词典序

以下是必须报告的结果族，不是供分析者事后挑选冠军的菜单。唯一冠军只由 §6.0 的主分析行决定；不使用 LLM 总分或任意加权“综合分”。辅助结果按以下顺序解释：

1. **RUL/生存**：
   - 可识别事件：每电容时间加权 MAE、MedAE、CRPS/WIS；区间删失结局使用与区间相容的 likelihood/proper score，不把端点或中点伪装成真值；
   - 含删失：只有删失机制假设可说明时才使用 IPCW integrated Brier score、time-dependent log score，并做信息性删失敏感性；否则标 `NA`；
   - 晚报单独以非对称损失报告。
2. **C/ESR 多步轨迹**：
   - 每目标、每 horizon 的 MAE/RMSE；
   - 相对 last-value 的 MASE；
   - 先按电容宏平均，再按已审计的应力电压/板卡/批次分组宏平均。
3. **不确定性**：
   - 50/80/90% empirical coverage、平均宽度、Winkler/WIS；
   - 全寿命和局部窗口 coverage。
4. **异常风险**：
   - AUPRC、Brier、ECE/可靠性图、提前量、每 1,000 h 或每 100 事件虚警。
5. **稳健性/成本**：
   - 最差电容、90 分位电容、最差电压；
   - 推理时延、内存、重训成本和 Agent 调用数。

### 6.2 PHM 辅助指标

- Prognostic Horizon。
- \(\alpha\)-\(\lambda\) performance：主报告 \(\alpha=20\%\)，其他值为敏感性。
- Relative Accuracy / Cumulative Relative Accuracy。

这些指标不替代原始误差和校准指标。

## 7. 统计比较

- 配对差异在相同“电容×预测原点×horizon”上计算，但置信推断以电容为 cluster。
- Benchmark S 只有 6 只电容：逐只结果、exact sign/permutation 检验和 cluster bootstrap 同时给出；不把窗口数当作样本量。
- 随机模型至少 5 个预注册种子；同时报告 seed 方差和每电容方差。
- 多候选比较用 Holm 校正；效应量和置信区间优先于 p 值。
- 晋级条件必须包含：
  - Freeze B 所指定主指标改善；
  - C、ESR 均不劣于冠军超过 Freeze B 的固定界限；
  - 90% 区间覆盖误差绝对值不超过 5 个百分点；
   - 最坏已审计应力电压/板卡/批次不恶化超过预注册界限。

由于样本极小，任何“显著”结果仍只限于这些公开加速试验。

## 8. 泄漏防护硬规则

1. **先按整只电容切分，再生成窗口。**
2. scaler、imputer、平滑器、频率选择、特征搜索和阈值只拟合内层训练电容。
3. 测试电容的 \(C_0/R_0\) 只能来自真实部署可获得的初始标定；禁止用全寿命最大/最小/均值归一化。
4. 禁止跨预测原点插值、双向平滑和使用未来窗口。
5. 禁止设备 ID、文件长度、最终循环数、终止标志及其代理进入模型。
6. RUL 只能由预注册 EOL/删失标签生成；`max_cycle-cycle` 是自动失败。
7. feature discovery Agent 只能读取训练侧视图；Eval 标签由隔离服务持有。
8. 基础模型的预训练数据污染无法完全排除时，必须报告该风险，并以传统基线和外部时间/工况测试作约束。
9. 每个预测保存 feature lineage；任何 future/Eval taint 传播到模型即使数值更好也判无效。
10. 在调参结束前不聚合外层结果给开发 Agent。
11. 预测账本必须通过时间戳不变量测试：延迟、删除或置换尚未成熟的未来/EOL 标签，成熟前所有预测哈希必须完全相同。
12. 首次外层解封后，任何代码、特征、模型、Skill 或 prompt 修改都只算探索性；除非获得新的时间、批次或外部数据，不能用同一外层数据恢复“独立测试”资格。

## 9. Agent 架构公平比较

Agent 拓扑是独立 meta-eval，不与物理模型主比较混为一篇因果故事。比较以下五种架构，但它们必须拥有相同：

- 基础 LLM、工具权限和总训练预算；
- 候选模型库；
- 数据视图；
- frozen Eval；
- 最大 wall-clock 和 token/GPU 预算。

| 架构 | 实现 | 必测风险 |
|---|---|---|
| 单 Agent | 一个 Agent 完成审计、建模和诊断 | 上下文污染、单点失败 |
| 固定多 Agent | 固定角色 DAG | 错误沿固定边传播 |
| 层级 Agent | 域内工作节点 + 独立治理节点 | 监督瓶颈、故障域 |
| 并行辩论 | 多提案 + 泄漏挑战；只能提交可执行反例 | 多数票偏差、成本 |
| 动态路由 | 依据训练侧风险遥测选择单 Agent/固定 DAG/辩论/恢复子图 | 路由过拟合、OOD 回退 |

主要 Agent 系统指标：

- 最终冻结模型的真实数值误差；
- 有效候选发现率；
- 泄漏/伪指标/不可复现补丁阻断率；
- 错误晋级率；
- 任务完成率、恢复率、调用和算力成本。

Agent 不直接预测 C/ESR/RUL；在线数值专家和可审计路由器负责预测。LLM Agent 只做代码、数据审计、候选生成、诊断和证据核查。

首轮只实现 `single Agent + deterministic validator` 基线与 `fixed typed DAG` 挑战者。只有 fixed 在隐藏任务、相同成本下优于 single，才允许依次评估 hierarchical、executable debate 和 dynamic routing。实验单位是独立数据审计/代码修复/隐藏故障任务，不是 Agent 轮次；按数据集、故障家族和代码模块做 meta-train/hidden-meta-test 隔离。

## 10. 影子验证与上线门

1. 保持已验证冠军，挑战者读取同一历史流但输出不影响冠军。
2. 影子期标签延迟与真实回放一致；结果写入哈希链账本。
3. 只有全部数值门通过，挑战者才可提交人类裁决。
4. 任何数据漂移、缺测、模型崩溃、路由 OOD 或证据链断裂都回退冠军。
5. `AUTO_PROCEED=false`：即使挑战者通过，也不得自动上线。

历史回放上的 shadow 只称“伪在线影子回放”；没有经历新的真实数据流和真实标签延迟，不称部署验证。

## 11. 本轮明确不执行

- 不下载/解压完整 5.04 GB 大包后的正式建模。
- 不启动 GPU 微调、LOCO/LOVO 正式训练或影子回放。
- 不报告任何尚未运行的 MAE、RMSE、覆盖率或 Agent 架构胜负。
- 等待人类批准本协议及存储/算力预算后再进入 pilot。
