**Frozen at:** 2026-08-24 14:51:30 CST  
**Review status:** same-family / provisional; web search by the executing Agent, not an independent external reviewer.  
**Claim under review:** a strictly causal, whole-unit, matched-observable-budget comparison of direct numeric LLMs, LLMs with the same numerical-expert packet, typed local numerical authority, deterministic action selection, and multi-agent/model-diversity variants for online capacitor prognostics.

## Decision

- **Novel Agent forecasting method:** **LOW novelty.** CAP-ACT must not claim that LLM routing, tool use, numerical-expert selection, fusion, reflection, or multi-agent decomposition is new.
- **Action-only typed controller:** **LOW novelty as a predictive mechanism.** It is a bounded router over frozen experts.
- **Capacitor-specific empirical architecture study:** **MEDIUM, unconfirmed.** The provisional delta is the controlled factorization and strict PHM evaluation, not a new forecasting model.
- **Top-ML method positioning:** **RED** unless a materially different persistent-program mechanism and multi-corpus evidence emerge.
- **PHM/reliability/industrial-AI empirical positioning:** **AMBER** pending audited real data, authenticated API runs, and a decisive result or well-powered null result.

## What remains potentially publishable

The narrow empirical question is not “can agents forecast time series?” It is:

> In physical degradation forecasting, after fixing future availability, whole-device splits, numerical experts, data bytes, physical attempts, requested ceilings, fallback and mature numerical scoring, which LLM authority boundary—free numbers, tool ID, fusion template, bounded correction, or unified finite Action—changes held-out risk, reliability and cost?

The sources above strongly cover direct LLM forecasts, tool-augmented time-series agents, multi-agent forecasting, LLM ensemble routing, and cheaper learned routing. The following combination was not verified as already jointly evaluated:

1. direct raw-history and byte-identical expert-packet direct controls;
2. arm-specific authority schemas with the same planned target–horizon denominator;
3. one physical attempt/no repair for accuracy, with late/unknown-usage/fallback costs retained;
4. prediction-before-reveal rolling replay and whole-capacitor macro statistics;
5. explicit target/censor eligibility gates and RUL=NA when unidentifiable;
6. a real 113-device degradation fleet plus a separately reported external capacitor domain;
7. a preregistered negative-result path that stops adding agents when numerical-only wins.

That is a **study-design delta**, not proof of method novelty. A full-paper search must inspect methods and supplements of the closest works, not rely only on abstracts.

## Required controls after this check

- Numerical: last value, drift, local linear/exponential, KF/state-space, ridge/GPR where gated, and a modern TSFM or learned router where sample size supports it.
- Direct LLM: D1-RAW and D1-PACKET.
- Hybrid: tool selection, fixed fusion, correction around a frozen base, and unified primary Action authority.
- Non-LLM routing: exhaustive/pessimistic ENUM-ACTION; add a lightweight learned router if training-unit power is adequate.
- Multi-agent: matched homogeneous versus heterogeneous direct/action proposals; debate/hierarchy/dynamic routing only as add-one controls.
- Cost/reliability: requested and realized tokens, physical attempts, end-to-end latency, usage completeness, failure/fallback and active coverage.
- Data: whole-unit LOCO/shadow, batch/protocol holdout, and no pooled windows as independent samples.

## Falsifiers

CAP-ACT loses its empirical contribution if a closest work is found to already provide the same authority-factorized, information-matched, failure-retaining whole-unit degradation replay. It loses scientific value if:

- numerical controls are weak or tuned on test units;
- gains vanish against D1-PACKET or a cheap non-LLM router;
- gains come only from extra calls, packet information or fallback;
- only Stress-2 or a confounded eight-unit domain is positive;
- active non-fallback coverage is too low;
- the Ren archive fails identity/target/split audit;
- endpoint-unknown units are scored as exact RUL.

## Safe novelty wording

> We present a controlled empirical study of direct and tool-grounded LLM Agent architectures for online capacitor degradation forecasting, with whole-device rolling replay, information- and attempt-aware controls, deterministic numerical authority, and failure-retaining evaluation.

Do **not** use: “first agentic time-series forecaster,” “novel LLM ensemble router,” “new multi-agent forecasting framework,” “program-synthesis expressivity,” or “causal counterfactual verification.”
